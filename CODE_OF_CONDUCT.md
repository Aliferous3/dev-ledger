# Code of Conduct

Dev Ledger's repository is intended to be a professional, constructive place to build software.

## Expected behavior

Participants should:

- discuss ideas and code on their merits;
- be specific and respectful in reviews and disagreements;
- assume good faith while still challenging unsafe or incorrect changes;
- respect privacy and never post another person's private repository data or personal information;
- accept maintainer decisions on project scope and security boundaries; and
- help keep issues and pull requests useful to future contributors.

## Unacceptable behavior

The following is not acceptable:

- harassment, threats, discriminatory abuse, or personal attacks;
- publishing private information without permission;
- deliberately exposing credentials, private repository content, or user data;
- spam, coordinated disruption, or repeated bad-faith interaction; or
- using security reports to threaten disclosure or cause avoidable harm.

## Enforcement

Maintainers may edit, hide, lock, or remove content and may restrict participation when necessary to protect contributors, users, or the project.

For sensitive conduct concerns, do not post personal details publicly. Use a private project/operator contact path where available.

This policy applies to repository issues, pull requests, reviews, discussions, and other project-managed spaces.
